The network

A CPPN: random weights, a random activation function per neuron, never trained. Its output is the terrain — six channels sampled per tile. Change its shape and you change the planet.

What h1 computes

Every neuron in the layer, over the same patch of map, from one forward pass. The terrain is a weighted sum of these. Click one to put it on the main map.

Latent vector z

Four extra inputs held constant across the map. Slide them and every coastline, desert and mountain range re-forms continuously — same weights, different world.

Offspring

Interactive evolution. Each candidate is this world's weights plus gaussian noise, with the odd activation function swapped. Pick one and it becomes the parent — the lineage is replayable from the permalink.

World dials

At 100% the terrain is purely the network's output. At 0% it is plain fractal noise — the same noise the network gets as input. Slide it to see exactly what the network is contributing.

Biome network

The only trained net here. It learned from a rule oracle, then generalised: it answers with a distribution, so borders come out blended rather than stepped.

Legend

Sixteen classes. What you see on the map is a probability-weighted blend of these, not a pick from them.
